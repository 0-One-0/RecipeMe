# RecipeMe
 
A web application that lets users save their recipes to their account, keeping everything in one place and making it easy to find what you're looking for. Includes a "random recipe" feature for when you can't decide what to cook, plus category filtering (meat, vegan, vegetarian) and smooth animations powered by GSAP.
 
**Author:** Marko-Antonio Linnér Carvajal
 
## Features
 
- Save and manage your own recipe collection
- Generate a random recipe from your library when you're not sure what to cook
- Filter recipes by category (meat, vegan, vegetarian)
- Responsive design — works on both desktop and mobile
- Smooth UI animations with GSAP
- User authentication via Supabase Auth
## Tech Stack
 
- **Framework:** React
- **Languages:** JavaScript, HTML, CSS
- **Animations:** GSAP
- **Database:** Supabase
- **Auth:** Supabase Auth
## Project Status
 
This project is in its early stages. Core functionality works: saving recipe data to the database and using Supabase Auth to verify and register users. The layout is responsive across phone and desktop, though the visual design still needs more polish to make it stand out.
